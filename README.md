# Expense Tracker

A Flask-based expense tracker web application.

## Features

- User registration
- Login system
- Expense tracking
- Reports
- Dashboard

## Technologies Used

- Python
- Flask
- HTML
- Tailwind CSS
- Bootstrap
- MySQL

## How to Run

1. Install Flask

```bash
pip install flask
```

2. Run application

```bash
python app.py
```

3. Open browser

```text
http://127.0.0.1:5000
```
